# Plantilla oficial

Coloca aquí la plantilla oficial de ICEX con este nombre exacto:

```
plantilla/PlantillaWord_ICEX_EstudioMercado_2024.docx
```

No se incluye en el repositorio porque es material de ICEX (logotipos, marca, NIPO).
Descárgala de la fuente interna habitual o pídesela a un compañero, y copia el archivo en esta carpeta.
Git lo ignora a propósito (`.gitignore`), así que no se subirá por error.

Si la guardas en otro sitio, usa `--plantilla /ruta/a/la/plantilla.docx`.
